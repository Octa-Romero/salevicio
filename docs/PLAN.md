
# SaleVicio — Plan de desarrollo

## Objetivo
Desarrollar y publicar un prototipo web funcional de una comunidad de videojuegos.

## Tecnologías
- Frontend: React, Vite y Tailwind CSS.
- Backend: Node.js y Express.
- Base de datos: PostgreSQL (Neon).
- Hosting: Netlify y Render.
- Control de versiones: Git y GitHub.

## Metodología
Desarrollo incremental mediante tareas pequeñas.

Cada tarea deberá:
1. Tener un objetivo definido.
2. Implementarse y verificarse.
3. Actualizar la documentación correspondiente.
4. Registrarse mediante un commit en español.

## Etapas
1. Inicialización del proyecto.
2. Especificación y planificación.
3. Base de datos PostgreSQL.
4. API REST del catálogo.
5. Interfaz React.
6. Favoritos y reseñas.
7. Pruebas y despliegue público.

## Fecha de entrega
20 de noviembre de 2026.

## Riesgos
- Problemas de conexión con la base de datos.
- Errores en el despliegue.
- Tiempo limitado de implementación.
- Uso de recursos gráficos sin autorización.

## Estrategia
Priorizar las funcionalidades esenciales y verificar tempranamente la publicación de la aplicación.
