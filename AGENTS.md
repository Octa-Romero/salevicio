
# AGENTS.md — SaleVicio

## Objetivo
Desarrollar un MVP funcional, sencillo y mantenible.

## Reglas de desarrollo
1. Respetar las reglas de negocio de docs/SPEC.md.
2. No agregar funcionalidades fuera del MVP sin aprobación.
3. Mantener frontend y backend separados.
4. Usar JavaScript, React, Express y PostgreSQL.
5. Validar los datos recibidos por la API.
6. Utilizar consultas SQL parametrizadas.
7. No almacenar secretos en el repositorio.
8. No incorporar imágenes sin autorización.
9. Agregar pruebas para las reglas de negocio.
10. Mantener actualizada la documentación.

## Control de versiones
- Un commit por tarea terminada.
- Mensajes de commits en español.
- Utilizar prefijos feat, fix, docs, test y chore.
- No realizar commits con funcionalidades rotas.

## Prioridades
1. Funcionalidad.
2. Persistencia de datos.
3. Validaciones y pruebas.
4. Diseño visual.
5. Mejoras adicionales.
